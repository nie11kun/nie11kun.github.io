net.ipv4.udp_rmem_min = 16384 net.ipv4.udp_wmem_min = 16384应用并核对生效：sysctl --system sysctl net.ipv4.tcp_congestion_control net.core.default_qdisc net.core.rmem_max3. 确认 TLS 证书权限与 WARP（可选）ls -l UFW 放行端口ufw allow 8443/tcp comment 'VLESS REALITY' ufw allow 443/udp comment 'Hysteria2 QUIC' ufw allow 40000:40500/udp comment 'Hysteria2 Port Hopping'2. 持久化端口跳跃转发（40000:40500/udp → 443/udp）为什么不推荐直接改 /etc/ufw/before.rules？若 VPS 上同时运行了 Docker（例如 RustDesk、自建容器），Docker 会维护自己的 nat 链；直接把 *nat :PREROUTING ACCEPT 写死在 before.rules 并在重载 UFW 时刷新规则，容易干扰甚至冲掉容器的端口转发。使用独立的 systemd oneshot 服务幂等追加一条 REDIRECT 规则更安全、可随时启停。创建 /etc/systemd/system/sing-box-hy2-hop.service（若第 2 节查到的公网网卡不是 eth0，请同步替换 -i eth0）：[Unit] Description=Hysteria2 UDP Port Hopping (40000-40500 -> 443) After=network-online.target ufw.service Wants=network-online.target [Service] Type=oneshot RemainAfterExit=yes ExecStart=/bin/sh -c 'iptables -t nat -C PREROUTING -i eth0 -p udp --dport 40000:40500 -j REDIRECT --to-ports 443 2>/dev/null || iptables -t nat -A PREROUTING -i eth0 -p udp --dport 40000:40500 -j REDIRECT --to-ports 443' ExecStop=/bin/sh -c 'iptables -t nat -D PREROUTING -i eth0 -p udp --dport 40000:40500 -j REDIRECT --to-ports 443 2>/dev/null || true' [Install] WantedBy=multi-user.target3. 全部启用并启动systemctl daemon-reload systemctl enable --now sing-box.service sing-box-cert-reload.path sing-box-hy2-hop.service7. 客户端接入与常见踩坑1.
